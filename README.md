# Startup CRM Lite – Backend

The backend REST API for Startup CRM Lite, a customer relationship management application that helps startups manage leads, customers, and follow-up activities.

## Live Application

- **Frontend:** https://startup-crm-lite-zeta.vercel.app
- **Backend:** https://startup-crm-lite-zcrl.onrender.com

## Features

- User registration and login
- JWT-based authentication
- Lead management APIs
- Create, read, update, and delete lead records
- Follow-up task management
- Dashboard statistics
- CORS configuration for frontend integration
- Error handling and API validation

## Technologies Used

- Node.js
- Express.js
- JavaScript
- JWT
- REST API

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/navyasree-1234/startup-crm-backend.git
```

### 2. Navigate to the backend folder

```bash
cd startup-crm-backend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file using the required variables from the project's configuration.

Never commit real secrets or credentials to GitHub.

### 5. Start the server

Use the start command defined in `package.json`.

## API Overview

The backend provides APIs for:
